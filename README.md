# Chat

تطبيق دردشة حقيقي يعمل كواجهة ويب مع Supabase + WebRTC.

## المزايا

- تسجيل وإنشاء حسابات.
- اسم مستخدم فريد ومشاركته كرابط مثل `?user=yasin`.
- محادثات مباشرة بين مستخدمين.
- رسائل فورية عبر Supabase Realtime.
- إرسال صور وفيديو وملفات.
- مكالمات صوتية وفيديو عبر WebRTC مع STUN.
- متوافق مع الجوال والكمبيوتر.

## التشغيل

1. أنشئ مشروعًا في Supabase.
2. افتح **SQL Editor** وشغّل كل محتوى `supabase-schema.sql`.
3. من إعدادات Auth يمكنك إيقاف Email Confirmation أثناء الاختبار لتسجيل الدخول مباشرة.
4. افتح الموقع، وضع **Project URL** و **Publishable/Anon Key** في شاشة إعداد الاتصال.
5. فعّل GitHub Pages للمستودع `main` إذا أردت نشر الموقع.

## ملاحظة عن المكالمات

WebRTC يحاول الاتصال مباشرة بين الجهازين. الشبكات الصعبة قد تحتاج TURN server للإنتاج حتى تعمل المكالمات بشكل موثوق خلف بعض أنواع NAT والجدران النارية. STUN مفعّل افتراضيًا.
